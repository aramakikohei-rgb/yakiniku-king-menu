A placeholder menu page for a MonBooking LINE booking demo. The LINE rich menu's "View menu" opens it (`?lang=th|en|ja`).
Every price and dish here is a sample, not Yakiniku King's real menu. The photos are from Unsplash (https://unsplash.com/license).
