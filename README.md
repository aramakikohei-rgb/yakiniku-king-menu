# Yakiniku King Thailand · demo menu

A demo menu page for a MonBooking LINE booking demo. The LINE rich menu's "View menu" opens it (`?lang=th|en|ja|zh`).

- Dishes, courses and the photos in `img/` are from Yakiniku King Japan (yakiniku-king.jp), used for the demo with the client's agreement. Thai prices and the translations are placeholders.
- `shops/` holds placeholder branch photos for the LINE shop picker, from Unsplash: ratchada.jpg (5ZUysqN1wsw), siam.jpg (wfa6Bc2R0S8), thonglor.jpg (yzUdrYIOzzU).
